# Contributing to Instagram DM Panel

Спасибо за интерес к проекту! Мы приветствуем вклад от сообщества.

## Как внести вклад

### Сообщение о багах

Если вы нашли баг, пожалуйста создайте issue с:
- Описанием проблемы
- Шагами для воспроизведения
- Ожидаемым и фактическим поведением
- Версией Node.js и ОС

### Предложение функций

Создайте issue с тегом "enhancement" и опишите:
- Какую проблему решает новая функция
- Как она должна работать
- Возможные альтернативы

### Pull Requests

1. Fork репозитория
2. Создайте feature branch (`git checkout -b feature/AmazingFeature`)
3. Commit изменения (`git commit -m 'Add some AmazingFeature'`)
4. Push в branch (`git push origin feature/AmazingFeature`)
5. Откройте Pull Request

### Код стайл

- Используйте ES6+ синтаксис
- Добавляйте комментарии для сложной логики
- Следуйте существующему стилю кода
- Тестируйте изменения перед commit

### Области для улучшения

- Добавление тестов (unit, integration)
- Улучшение селекторов Instagram (они могут меняться)
- Поддержка нескольких аккаунтов
- Миграция на BullMQ + Redis для очередей
- Добавление веб-хуков
- Интеграция с другими соцсетями
- Улучшение UI/UX

Спасибо за ваш вклад! 🙏
