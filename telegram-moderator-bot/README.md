# Telegram Moderation Bot

Простой бот для модерации чатов Telegram.

## Возможности

- Автоматическое удаление сообщений с запрещёнными словами
- Антиспам (мут за слишком частые сообщения)
- Система предупреждений (warn)
- Мут/бан/кик пользователей
- Настраиваемые параметры модерации
- Поддержка владельцев бота (работают в любом чате)

## Установка

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Создайте .env файл
cp .env.example .env

# 3. Получите токен у @BotFather и добавьте в .env
TELEGRAM_BOT_TOKEN=ваш_токен

# 4. Запуск
python bot.py
```

## Настройка бота

1. **Создайте бота** у [@BotFather](https://t.me/BotFather):
   - Напишите `/newbot`
   - Следуйте инструкциям
   - Скопируйте токен

2. **Отключите Privacy Mode** (важно!):
   - Напишите `/mybots` в @BotFather
   - Выберите вашего бота
   - Bot Settings → Group Privacy → Turn off
   - Это позволит боту видеть все сообщения в чате

3. **Добавьте бота в чат** как администратора с правами:
   - Удаление сообщений
   - Ограничение участников (мут)
   - Блокировка участников (бан)

4. **Настройте владельца**:
   - Напишите `/myid` чтобы узнать свой ID
   - Напишите `/addowner ваш_id`

## Команды

### Для всех
| Команда | Описание |
|---------|----------|
| `/help` | Справка по командам |
| `/rules` | Правила чата |
| `/myid` | Показать ваш ID |

### Модерация (ответом на сообщение)
| Команда | Описание |
|---------|----------|
| `/mute [время]` | Замутить пользователя |
| `/unmute` | Размутить |
| `/ban` | Забанить |
| `/kick` | Кикнуть |
| `/warn` | Выдать предупреждение |
| `/unwarn` | Снять предупреждение |

### Запрещённые слова
| Команда | Описание |
|---------|----------|
| `/addword слово` | Добавить в чёрный список |
| `/delword слово` | Удалить из списка |
| `/words` | Показать все слова |

### Настройки
| Команда | Описание |
|---------|----------|
| `/setspam 5 10` | Антиспам: 5 сообщений за 10 сек |
| `/setmute 300` | Время мута: 300 сек |
| `/setwarn 3` | Предупреждений до мута: 3 |
| `/addowner ID` | Добавить владельца бота |
| `/addadmin ID` | Добавить админа бота |
| `/status` | Статус и настройки |

### Формат времени
- `30s` - 30 секунд
- `5m` - 5 минут
- `1h` - 1 час
- `1d` - 1 день

## Права доступа

Бот проверяет права в таком порядке:

1. **Owner (владелец бота)** - полный доступ во всех чатах
2. **Admin бота** - полный доступ во всех чатах
3. **Admin чата** - доступ в своём чате
4. **Creator чата** - доступ в своём чате

Это значит, что если вы владелец бота, вы можете модерировать любой чат, куда добавлен бот.

## Конфигурация

Настройки хранятся в `config.json`:

```json
{
  "banned_words": ["спам", "реклама"],
  "spam_threshold": 5,
  "spam_interval": 10,
  "mute_duration": 300,
  "warn_before_mute": 3,
  "owner_ids": [123456789],
  "admin_ids": []
}
```

## Примеры использования

```
# Замутить на 10 минут (ответом на сообщение)
/mute 10m

# Добавить запрещённое слово
/addword казино

# Настроить антиспам: мут если >10 сообщений за 30 сек
/setspam 10 30

# Добавить себя владельцем
/myid
/addowner 123456789
```
